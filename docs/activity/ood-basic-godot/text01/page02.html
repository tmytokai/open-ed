まず、以下の手順で演習で使用するプロジェクトのテンプレートを登録してメインシーンを作成してください。


プロジェクトの登録とメインシーン作成

プロジェクトのテンプレートをダウンロードして展開する

Godotを起動し、展開したテンプレートをインポートする

メニューから「シーン → 新しい継承シーン」を選択し、「world.tscn」を選ぶ

シーンドックの「World」を「MyWorld」に変更する

シーンドックの「MyWorld」を右クリックして「スクリプトを拡張」を選び、そのまま作成ボタンを押してMyWorldのスクリプトファイル(my_world.gd)を作成する

シーンドックの「Sprite2D」をクリックしてSprite2Dのインスペクタを表示する

インスペクタの「Texure <空>」をクリックし、「読み込む」をクリックして「img/MyWorld.jpg」を選択する

上の方にある「2D」をクリックして2D画面を表示し、背景画像(800x450)が表示されていることを確認する

Ctrl+s を押してMyWorldシーン(my_world.tscn)を一旦保存する

右上の「現在のシーンを実行(F6)」を押すかF6キーでゲームを実行する。すると背景の下の部分が見切れていることを確認する

表示領域を拡大する。メニューから「プロジェクト → ブロジェクト設定」で設定ダイアログを表示し、「一般タブ → 表示 → ウィンドウ」を選択し、「ビューポートの幅」を800、「ビューポートの高さ」を450にすると表示領域のサイズが背景画像と同じになる
