_process関数の移動部の下あたりに次のコードを追加する(先頭のスペースの数が違うとエラーが出るので注意する)

ソース 1: "a"を押したら Label にHelloと表示、"s"を押したら消す 
	# Input.is_action_just_pressed 関数でキーを押しているか1度だけチェック出来る
	# is_action_pressed 関数と違ってキーボードから指を離さない限り再びTRUEにならない
	if Input.is_action_just_pressed("a"):
		# Labelに文字列セット
		# シーンツリーでTAROからみるとLabelはひとつ上の階層のCanvasLayerの中にあるので
		# $"../CanvasLayer/Label".text = "Hello" でも可
		$"/root/MyWorld/CanvasLayer/Label".text = "Hello"
		# Label表示
		$"/root/MyWorld/CanvasLayer/Label".show()
	if Input.is_action_just_pressed("s"):
		# Label非表示
		$"/root/MyWorld/CanvasLayer/Label".hide()


右上の「現在のシーンを実行(F6)」を押すかF6キーでゲームを実行し、"a"で Label に Helloと表示、"s"で表示が消えるのを確認する

ラベルを増やしたい場合は「Label」を右クリックして「複製」を選ぶ
