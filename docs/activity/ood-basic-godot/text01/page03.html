キャラクターの作成と配置

メニューから「シーン → 新しい継承シーン」を選択し、「actor.tscn」を選ぶ

シーンドックの「Actor」を「TARO」に変更する

シーンドックの「TARO」を右クリックして「スクリプトを拡張」を選び、そのまま作成ボタンを押してTAROのスクリプトファイル(taro.gd)を作成する

シーンドックの「Sprite2D」をクリックしてSprite2Dのインスペクタを表示する

インスペクタの「Texure <空>」をクリックし、「読み込む」をクリックして「img/TARO.png」を選択する

上の方にある「2D」をクリックして2D画面を表示し、画像(50x57)が表示されていることを確認する

シーンドックの「CollisionShape2D」をクリックしてCollisionShape2Dのインスペクタを表示する

インスペクタの「Shape <空>」をクリックし、「CapsuleShape2D」を選択し、2D画面で当たり判定の領域を調整する

Ctrl+S を押してTAROシーン(taro.tscn)を一旦保存する

メイン画面の上にある「my_world」タブをクリックして MyWorld シーンに切り替える

シーンパネルの「MyWorld」を右クリックして「子シーンをインスタンス化 → taro.tscn」を選ぶとTAROが表示される

TAROをドラッグして適当な位置に移動する

同様にしてTAROを3人(TARO、TARO2、TARO3)表示する

シーンパネルの「TARO3」を右クリックして「削除」を選ぶとTARO3が消えることを確認する

右上の「現在のシーンを実行(F6)」を押すかF6キーでゲームを実行してTAROが2人表示されることを確認する
